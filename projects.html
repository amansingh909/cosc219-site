Projects

security-harness

This is the project I am working on right now. It is a set of tools for bug bounty research on targets I am allowed to test, built as four smaller programs that all read from the same CVE database. The recon part refuses to run unless I hand it a scope first, and anything it finds comes back labelled unverified, so I still have to confirm a lead myself before it goes in a report.

Inside security-harness

The four tools that make security-harness, and the service they all read from
Part What it does How it runs
harness The front door that drives everything else Interactive terminal app
cve-index Search over NVD and MITRE ATT&CK data Long-running service
cve-classifier Tags a CVE with a severity and a CWE Batch job on a GPU
recon-orchestrator Scope-gated recon that ranks what it finds Runs once, then stops
bounty-reporter Turns a confirmed finding into a report Command line tool
